# Pi token 与费用隔离验收

验收目标：同一任务、相同证据和交付要求下，总 token 与统一口径估算费用均不超过基线的 70%，质量不回退。未通过前不改变日常 Pi 模型、设置、扩展或桥接链路。

## 隔离与计量

`tools/token-cost-bench.mjs` 是显式运行的试验工具，不是常驻扩展，没有自动切换入口。

- 通过 `--cases` 显式加载本机私有用例定义，读取原会话，固定用户问题与工具证据，以内容哈希确认两组输入一致；不提供原任务最终答案。私有工作内容、断言及测试答复不提交公开仓库。
- 用原用户消息边界固定任务；后续追加对话不改变用例。续问用例给两组恢复相同前文，只统计本次任务及其压缩成本，不将前面已完成任务的历史费用重复算入本次。
- 两组使用同一 Pi SDK、模型、推理档位和价格表。交换部分用例执行顺序；不预热缓存，不丢弃冷请求。
- 独立输出目录、内存会话与设置。模型仅能调用 `evidence`，不能执行 shell、写文件、连接数据库或浏览器。
- 仅复用本机进程内凭据读取器，不复制凭据、原会话或浏览器登录数据。模型目录缓存仅写隔离目录。
- 总 token 包含未缓存输入、缓存读写及输出；推理已包含在输出中，不重复相加。原生压缩 usage 单独收集后计入总额。
- 费用按同一固定模型目录价格逐请求重算，包含长上下文价格档。Codex 订阅的目录估价不等于实际月账单。
- usage 缺失、字段不守恒、失败、取消、超时或未完成，均阻止验收；未知用量不得按零成本宣称成功。
- 每 15 秒记录运行进展；达到试验止损线只判未完成，不将中途消耗作为节省成绩。

## 候选与循环

| 候选 | 唯一变化 | 验证重点 |
|---|---|---|
| `batch` | 明确要求合并独立证据读取、避免重复读取和中间长报告 | 模型调用轮数是否真的减少，而非仅答案变短 |
| `dictionary` | 原始文本的可逆字典编码 | 每字节还原相等；字符缩短不等于 token 节省，收益不足时不启动付费试验 |
| `native-compact` | 通过 `--context-target` 指定原生压缩触发点，默认 64,000 token，最近保留量仍为 20,000；对照为默认约 255,616 | 分开检查新任务与长会话续问；压缩调用、压缩后冷输入、反复补读全部计费，检查关键要求和证据是否丢失 |

原生触发公式为 `contextWindow - reserveTokens`。当前官方 Pi 支持工具循环内压缩，无须自建记忆索引或常驻编排器。`reserveTokens` 同时影响摘要输出预算，不能把调低触发点当成无副作用的生产优化。

循环为：单元验证 → 固定证据对照 → 定位调用数、输入体积、推理输出或压缩开销 → 更换有证据支持的候选。相同路径两次无新收益即停，不无上限试提示词。

## 质量与切换门槛

1. 每个用例独立检查事实、关键数值、证据引用、未知项、安全边界及具体建议；正则检查只是初筛，不能替代逐项阅读。
2. `qualityReviewed` 默认为 false；没有明确复核，`comparePair` 不会通过。质量、完成状态及 usage 必须同时通过，再判断两项 0.70 阈值。
3. 固定证据回放不包含原始资料采集、实时状态变化、代码修改、部署或浏览器交互，不能用其收益宣称完整生产任务达标。
4. 有候选通过初筛后，才在隔离工作副本补齐真实取证、代码修改及现有回归测试；正反顺序重复至少三轮，并增加未用于调参的任务。所有重试、辅助调用和必要补读计入对应完整任务。
5. 重复与留出任务全部满足质量门槛及两项降幅后，只切换已验收的任务范围。修改前 `bak`，双机只同步变更配置行并读回，不重启或中断现有任务。
6. 回归时还原本轮精确备份，保留会话和试验记录。任何未通过原因必须显式记录；不能静默降级或自动换模型。

## 运行

免费契约测试：

```bash
node --test tests/token-cost-bench.test.mjs
```

显式模型试验，`--out` 必须是生产 agent 目录之外的新目录：

```bash
node tools/token-cost-bench.mjs --package "<当前 pi-coding-agent 包目录>" --cases "<本机私有用例模块.mjs>" --out "<新的隔离目录>" --candidate batch --max-usd 4
```

用例模块默认导出数组，每项包含 `id`、原会话文件名 `prefix`、非空正则断言 `checks`；长会话续问加零起点 `userIndex`。模块是本机受信代码，不加载网络来源。候选可换成 `dictionary` 或 `native-compact`，用 `--case` 选定用例，`--context-target 128000` 改变隔离压缩触发点。产物为 `summary.json`、进展日志、每组答复和逐请求 usage；不保存推理正文或凭据。费用上限在完整请求返回后检查，最后一笔请求可能超出止损线，不是服务端硬预算。

官方依据：当前安装版本的 `docs/sdk.md`、`docs/compaction.md`、`docs/settings.md`；[OpenAI Prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching)。
